```
→ ★不是"XAU 数据尾部滞后"，而是 XAU 覆盖范围内的【真缺口】
```

### 2.3 ★缺口的形态：每日固定

```
2024-02 窗口（2024-03-01 请求）的 MISS 样例：
  2024.02.29 22:30 / 22:00
  2024.02.28 22:30 / 22:00
  2024.02.27 22:30 / 22:00
  2024.02.26 22:30 / 22:00
  2024.02.25 22:30 / 22:00
  2024.02.22 22:30 / 22:00
  …
★每天固定缺失 22:00 与 22:30 UTC 两根
★XAU 每日首根 = 23:00 UTC（2022.01.02 23:00 / 2023.01.02 23:00 / 2024.03.01 之前均为 23:00）
★JPY 同期全程连续（含 22:00 / 22:30）
```

### 2.4 量化解释

```
每天 48 根 M30（24h × 2）
XAU 每天固定缺 2 根 → 2 / 48 = 4.1667%
→ 理论 alignment 上限 ≈ 95.83%
→ 实测 95.05% ~ 95.40%（差额来自节假日/半月休市）
★完全吻合，说明缺口是【确定性的、每日重复的】，不是随机数据缺失。
```

### 2.5 与 JSB30 的一致性

```
JSB30 时期已独立观测到同一现象：
  "XAU M30 first=2023.01.02 23:00"（而非 22:00）
  而 JPY M30 first=2023.01.01 22:00
→ 两次独立测量一致，交叉验证成立。
```

## 3. 为什么这是【结构性】而非【可修复】

| 可能的解释 | 是否成立 |
|---|---|
| 本地缓存滞后 / 同步不完整 | ❌ `miss_beyond_xau_end = 0`，缺口在覆盖范围【内】 |
| 重新同步可补齐 | ❌ 缺口每日重复且形态固定，同步后仍会重现 |
| 请求窗口过窄 | ❌ 用 1 个月与 6 个月窗口测，结论一致 |
| 品种不存在 | ❌ `XAUUSDm` 为真实券商品种，`server_minus_GMT_sec=0` 正常 |
| **品种交易时间差异（黄金交易所每日结算/休市窗口）** | ✅ **唯一与全部证据相符的解释** |

**→ XAU 与 JPY 的 M30 时间轴在每日 22:00–23:00 UTC 区间天然错位，
该错位是品种属性，不可能通过任何数据操作消除。**
