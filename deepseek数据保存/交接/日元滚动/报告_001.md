### 2.2 设计取向：为什么用「篮子均价」而不是「逐层止盈」

网格有两种常见实现，我选了较保守但**结构上更健壮**的一种：

| | 逐层止盈（经典网格） | **篮子均价止盈（本 EA）** |
|---|---|---|
| 出场 | 每层各自在入场价 ±TP 平仓 | 全部层在 **成交量加权均价 ±TP** 一起平仓 |
| 记账状态 | 必须逐层追踪 ticket | **只需 (anchor, layers) 两个数** |
| 净额账户(Netting) | ❌ 多张单会被合并，逐层 TP 失效 | ✅ 天然可用 |
| 对冲账户(Hedging) | ✅ | ✅ |
| 券商侧强平(SL/SO) | 会打乱层记账 | **Reconcile() 自愈**（以实际持仓为准） |

**关键点：层数守恒。** 因为本 EA **不设券商侧 TP/SL**，层只会在"篮子平仓"时一起消失，
所以 `layers` 与 `anchor` 是可靠状态；再加 `Reconcile()` 每 tick 用实际持仓自愈，
**不存在"记账与实际脱节"这一类 bug**（我特意避开了前一条线踩过的 ticket 映射坑）。
