## 3. §B ★★★ ρ 的完整解剖（本报告最重要的方法论结论）

### 3.1 预登记结果（候选 = 训练段 net>0 的 17 组，M15）


**★★【事实】用验证段挑出来的配置，在测试段是 −7.55；而直接用训练段第 1 名，测试段是 +2.00。**
**验证段这一步不但没帮忙，还把结果从 +2.00 拉到了 −7.55。**

### 3.2 ρ 与随机对照

| 指标 | M15（n=17 候选） |
|---|---:|
| **ρ(验证段, 测试段)** | **−0.480** |
| ρ(训练段, 测试段) | **+0.363** |

所以上面这些数只能算"强烈的方向性提示"，**不能当成显著性结论**。→ 我因此做了 §3.3 的扩样。

### 3.3 ★★★ 扩样后我推翻了自己的"大结论"（控制实验）

把候选集放宽到**只过频率门槛**（不加 net>0），n 从 17 涨到 108(M5)/93(M15)：

| | M5（n=108） | M15（n=93） |
|---|---:|---:|
| ρ(验证段, 测试段) | **+0.844** | **+0.106** |
| ρ(训练段, 测试段) | +0.824 | +0.053 |
| ρ(训练段, 验证段) | +0.890 | −0.143 |
| 验证段 top5 ∩ 测试段 top5 | 0/5（随机期望 0.23/5） | 2/5（随机期望 0.27/5） |

**M5 的 +0.844 看起来"预测力极强"。我本来准备把它写成正面结论 —— 然后我做了控制实验。**

**控制实验**：M5 上 `EntrySigma` 越大 → 笔数越少 → 成本拖累越小，**三个段都单调**。
→ 段间排名一致可能只是"`EntrySigma` 的排序在每段都一样"，**与预测力无关**。
→ **把 `EntrySigma` 固定住（组内 n=27）再算 ρ**：

| | EntrySigma=1.2 | =1.7 | =2.2 | =2.7 | **组内均值** | 未控制时 |
|---|---:|---:|---:|---:|---:|---:|
| **M5** ρ(验证,测试) | +0.168 | −0.042 | +0.294 | +0.351 | **+0.193** | +0.844 |
| **M15** ρ(验证,测试) | −0.046 | +0.274 | **+0.687** | +0.161 | **+0.269** | +0.106 |

**★★【事实】M5 的 ρ 从 +0.844 塌到 +0.193。我的怀疑成立：那个高分是「笔数→成本」单调主效应的假象，不是预测力。**
**→ 我撤回本报告初稿里"JPY 的 M5 上验证段有强预测力"的说法。它不成立。**

**★【推断 · 中置信】修正后的结论（比"ρ≈0"精确得多）**：
> **在同一个参数邻域内（固定 EntrySigma），验证段排名对测试段有 ρ ≈ +0.17 ~ +0.27 的【弱正持续性】。**
> **它既不是"完全无预测力"（ρ≠0），也远不到可用（top5 命中仍是随机的量级）。**
> **而且更关键的是：三段的整体水平都是负的，所以"排得准"没有任何用 —— 排得最准也只是挑出"亏得最少"的那个。**

**→ 这直接回答了用户的原始期待**（"通过前 6+3 个月调整参数，让模型符合当前情况"）：
**在 JPY 上，滚动重估参数能挑出"相对没那么差"的配置，但挑不出"正期望"的配置 —— 因为训练段里就没有正期望的配置。**

### 3.4 一个必须标出来的方法论警告

**测试段是三个段里最好的**（M15 段均值：训练 −10.57 / 验证 −2.90 / **测试 +0.65**；M5：−87.77 / −49.45 / **−23.46**）。

**→ 【推断 · 高置信】这是【时段效应】，不是方法有效。** 2023.03–05 这三个月对 `dsh_JPYRev` 就是比 2022.06–11 好。
**→ 后果：如果只汇报"测试段拼接出来的 OOS 曲线"（这正是滚动优化的标准交付物），我汇报的会是"一个恰好有利的时段"，而不是"方法的技能"。**
**→ 这条适用于所有线**：n=1 个窗口的 OOS 曲线**不能**当作能力证据；必须多窗口才能把时段效应平均掉。

## 5. §D ★★★ 【事实】网格冒烟：把点差剥出来之后，答案很清楚

**口径**：`jyrg-g-smokeL`，2022.06.01–2023.05.31（12 个月），只做多，`MaxLayers=8 / lot=0.01 / BasketStopPct=15 / ER门开 0.35 / 无冷却`，扫 `步长×止盈 ∈ [100,500]²`
**总览**：**25 pass 全部执行（穷举生效 ✅）**，`trades` 462–2435（**中位 894，即 894 笔/年**），`0 笔` 的 pass = **0**（**EA 确实在交易，机制是通的**）
**net**：−295.19 ~ **−10.39**（中位 −190.36）· **net>0 的数量 = 0** · **PF max = 0.995** · **dd 71.88% ~ 99.10%**

### 5.1 点差剥离（这是本报告最有用的一个诊断）

每平掉 1 层 = 0.01 手、往返 10 点 = **$0.0649**（按 154.099 折算）。
`毛边际/笔 ≡ expected_payoff + $0.0649`：

| pass | 步长 | 止盈 | trades | expected_payoff | **毛边际/笔** | 毛边际 > 点差? | 总点差$ | net |
|---:|---:|---:|---:|---:|---:|:--:|---:|---:|
| **22** | 300 | **500** | 701 | −0.0148 | **+0.0501** | **否** | 45.5 | **−10.39** |
| 3 | 400 | 100 | 1610 | −0.0959 | −0.0310 | 否 | 104.5 | −154.46 |
| 19 | 500 | 400 | 555 | −0.0973 | −0.0324 | 否 | 36.0 | −54.02 |
| 7 | 300 | 200 | 1155 | −0.1081 | −0.0432 | 否 | 75.0 | −124.85 |
| **0** | 100 | 100 | **2435** | −0.1198 | −0.0549 | 否 | **158.0** | −291.69 |
| … | | | | | | | | |
| 23 | 400 | 500 | 473 | −0.4692 | −0.4043 | 否 | 30.7 | −221.94 |

**★★【事实】25 组里【毛边际为正】的只有 1 组（pass 22，+$0.0501/笔）；而它【仍小于点差 $0.0649/笔】。**
**★★【事实】也就是说：在 100–500 点这个尺度上，网格连【扣点差之前】的期望都基本是零或负的。这不是"成本太贵"，是"没有毛优势"。**

**★这推翻了我自己在 `报告_001` §2.4 里给的乐观口径**：我当时算的是"点差只占止损距离的 5%，所以网格在成本上可行"。
**那个算法只算了点差相对于目标距离的比例，没算"毛边际"本身。正确的判据是 `毛边际/笔 > 点差/笔`，而它不成立。**

**★另一个必须看懂的规模事实**：中位 894 笔/年 × $0.0649 = **$58/年**，在 $300 账户上是 **19.3%/年**。
pass 0（2435 笔）的点差总额 $158 = **净值的 53%/年**。**这个换手率下，即使毛边际为零也会被点差磨死。**

|---:|---:|---|---:|---:|

### 5.3 死亡螺旋诊断（DD 72–99% 是怎么来的）

**算术上，8 层 × 0.01 手在 $300 上的满仓最坏浮亏只有 $36.34 = 12.1%**（`risk_math.py`）。
**→ 所以 72–99% 的 DD 不是浮亏造成的，只能是【连环篮子止损】造成的：**
每次 `BasketStopPct=15%` → 平掉 → `InpCooldownMinAfterStop=0` → **同一个 tick 立刻重新锚定开层** → 又在趋势里被止损 → 又 −15%……
`0.85^k`：要走到 99% 需要 k ≈ 28 次。**配合 894 笔/年的换手率，这在 12 个月里完全做得到。**

**→ 【推断 · 高置信】冒烟用的是 `CooldownMinAfterStop=0` + `BasketStopPct=15%` 的组合，是网格最坏的配置形态。**
**→ 这正是第二部分第一个网格（`jyrg-g2-cd`）要直接检验的东西。**
