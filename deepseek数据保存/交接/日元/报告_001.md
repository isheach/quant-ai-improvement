## 1. ★★ 五处需要更正的既有说法（全部为源码直读，已逐行重读）

### 1.1 `InpTrendTF` 的"默认值 30"是**错的**；30 是 `BASE_PARAMS` 覆盖值

- `dsh_TrendCore.mq5` **L60**：`input ENUM_TIMEFRAMES InpTrendTF = PERIOD_M5;`
  → **EA 自身默认是 M5**（`PERIOD_M5`=5）。
- `runexp.py` **L130**：`"InpTrendTF": "30",` → 属于 `BASE_PARAMS`（L127–159）。
  → **实际回测跑的是 M30**，因为 `batch_run.py` L144–145 把 `BASE_PARAMS` 与请求覆盖项 `merged.update(...)` 合并。

**为什么必须写清楚**：用户在任务书里把 `InpTrendTF(30)` 列成"关键参数"，容易被读成"EA 内置默认 M30"。
**真实语义是：不写 `InpTrendTF` 就得到 M30（走基线），要 M5 必须显式写 `"InpTrendTF":"5"`。**
本批 jpy-006/010/011/012/016 走的就是显式 M5 路线。

### 1.2 ATR 是在 `InpTrendTF` 周期上算的，不是固定 M30

- L909–916 `EvalSignal()`：`GetView(InpTrendTF, InpBreakoutBars, v); ... atr = v.atr;`
- `runexp.py` L143–146：`InpSL_ATR` / `InpTrail_ATR` / `InpTP_ATR` 的注释口径是"ATR(M5)"，**EA 源码 L75 的组名叫 `=== 止损 / 止盈 / 移动止损（全部 ATR(M5) 倍数）===`**。
  → **组名里的 "M5" 是按 EA 默认 TF 写的，实际倍数乘以的是 `InpTrendTF` 周期的 ATR。**

**后果（这是量纲的核心）**：把 `InpTrendTF` 改成 5，**止损/止盈距离会跟着一起缩小约 3–5 倍**。
黄金线上 `gold-011`（M5+SL2.5）与 `gold-013`（M15+SL1.0）的对比就是这个效应。**JPY 的 tp/sl 绝对点数必须先看 `trades.csv::atr_at_entry` 才能落地。**

### 1.3 单仓硬约束（频率天花板的第一根梁）

- L1268–1272：
  ```
  if(HasPosition())
  {
     ManageOpenPosition();
     return;   // 单仓模式：有仓时不开新仓
  }
  ```
  → **持仓期间一律不开新仓，没有加仓、没有对冲、没有反向翻仓。**
- L1275：`if(!IsNewBucket(InpTrendTF, g_lastBarM5)) return;`
  → **入场只在 `InpTrendTF` 新根上评估一次**（函数名和变量名 `g_lastBarM5` 是历史遗留，实际传的是 `InpTrendTF`，我重读该行确认）。
  → **推论：JPY 训练段理论最大笔数 ≈ 10.38 年 × 每年 bar 数 × 仓位周转率**，仓位周转率 < 1。

### 1.4 风控闸门在信号之前就有 4 个 early-return（频率天花板的第二根梁）

L1277–1281 依次：
```
1277:    if(g_ddLocked) return;
1278:    if(g_dailyBlocked) return;
1279:    if(!SessionAllowsOpen()) return;
1281:    if(InpUseRVGate && g_rvPct > 0.0 && g_rvPct < InpRVMinPct) return;
```
→ **净值回撤锁 / 日损阻断 / 时段 / RV 波动率闸门，任一触发就整根 bar 不评估**，且**不产生任何"信号被拒"的计数**。
→ **这正是黄金线 `报告_002.md` §1 里"静默停摆"最可能的正式解释路径**：`gold-023/024/025` 用关锁/开关日志去反推它。**我在 JPY 上不重复猜，直接用同样的关闸法隔离（jpy-002/004/005/006 + jpy-010 日志）。**

### 1.5 `InpAllowMinLotOvershoot` 默认 true + `InpMinLotMaxRiskPct` 默认 3.0 → 单笔风险可达 3%

- L56–57：
  ```
  input bool   InpAllowMinLotOvershoot = true; // 算出的手数小于券商最小手时，允许按最小手交易
  input double InpMinLotMaxRiskPct = 3.0;    // 上述模式下的风险硬上限（占净值%）；超过就放弃该信号
  ```
- **USDJPYm 实测规格**（`analysis\out\broker_specs_20260910.json` L55–74 直读）：
  `digits=3, point=0.001, contract_size=100000, volume_min=0.01, volume_step=0.01, stops_level_points=0, spread_points=10, tick_value=0.64889`
- 换算：**0.01 手 × 1 point(0.001) = $0.006489**
  → 训练段汇率约 100–160 时略有浮动，任务书用 $0.0065/点，二者一致。

**结论（算术，非推断）**：`InpMinLotMaxRiskPct=3.0` + 入金 300 → 单笔最大可承受风险 **$9.00** → 止损距离上限 **$9.00 / $0.006489 ≈ 1387 points = 1.387 日元**（约 139 pip）。
**JPY 的 ATR(M30) 若超过 ~0.55 日元（55 pip），2.5×ATR 就会被这个闸门整批拒掉。** 2022 年干预行情段 ATR 会远超此值。
→ **这是"高波动年份自动停摆"的机制候选，必须用 jpy-005（cap 放宽到 20%）对照验证。**

## 4. ★ 频率上界的机制推导（推断，本批 22 条就是为检验它而设计）

**已知约束**：单仓（§1.3）+ 4 道 early-return（§1.4）+ 信号必须同时满足 4 个条件。
**重读信号条件（L918–942）**：

```
918:    bool breakoutUp = true, breakoutDown = true;
919:    if(InpBreakoutBars > 0)
920:    {
921:       breakoutUp   = (v.close1 > v.hiPrior);
922:       breakoutDown = (v.close1 < v.loPrior);
923:    }
925:    bool up   = (v.fast > v.slow) && (v.slow > v.slowOld) && breakoutUp;
926:    bool down = (v.fast < v.slow) && (v.slow < v.slowOld) && breakoutDown;
929:    if(InpUseTrendConfirm && InpTrendConfirmBars > 1)
935:       if(up   && g_confirmUp   < InpTrendConfirmBars) { why = "confirm_up";   return 0; }
936:       if(down && g_confirmDown < InpTrendConfirmBars) { why = "confirm_down"; return 0; }
```

→ **入场 = 三重合取**：①快慢 EMA 同向 ②慢 EMA 有斜率 ③收盘创 `InpBreakoutBars` 根新高/新低；再加 ④连续 N 根确认（默认开、N=3）。

**四个可动的频率旋钮（按预期杠杆排序，这是我的推断）**：

| 旋钮 | 机制 | 预期效应 | 本批请求 |
|---|---|---|---|
| **`InpTrendTF` 30→5** | 评估点从 48/天 → 288/天；ATR 同时缩小 | **杠杆最大**（gold-031: M15 让 1248 笔 vs M5 的 457 笔量级差异都出现过） | jpy-006/010/011/016 |
| **`InpUseTrendConfirm` false** | 去掉"等 3 根"，抢首根突破 | 在黄金上 gold-030 把 226→415 笔（**+84%**） | jpy-003/006/011 |
| **`InpBreakoutBars` 30→15** | 更容易被突破 | 中等；黄金 gold-031 469→479（+2%，**效果很小**） | jpy-006/011 |
| **`InpUseSessionFilter` false** | 8–21 时 → 24 小时（+37.5% 可交易小时） | 中等 | jpy-004/006 |

**推断 I-1（★本批最重要，可证伪）**：**JPY 的 M5 全放开配置能在训练段做到 ≥1040 笔（≥100 笔/年）。**
**为什么我敢推**：`jpy_2024h1` 用 M30 默认参数已经 57.6 笔/年；M5 评估点是 M30 的 6 倍，且 JPY 在亚盘/欧盘都有连续流动性（不像黄金只靠美盘）。
**若 I-1 被证伪（jpy-006 仍 <1040）**：那 JPY 的**结构性频率上界就不够**，我会立刻在 `报告_002.md` 里把这条作为**需要向用户提交的取舍**（而不是偷偷放宽门槛）——这正是用户"低频=拟合"警告要我做的事。
