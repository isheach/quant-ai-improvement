## 2. ★★按 R 口径重算：集中度问题显著减轻（这是对我报告_011 §2 的修正）

我用 `risk_money` 列按 **R = pnl / risk_money** 重算 `gold-100`（578 笔）：

| 指标 | **R 口径（正确）** | 美元口径（我报告_011 用过，有偏） |
|---|---:|---:|
| 总 R | **+363.39** | +482.55（美元） |
| **前 5 大单占比** | **43.9%** | 63.1% |
| **前 10 大单占比** | **79.0%** | 99.9% |
| **去掉前 10 大单后** | **+76.27R**（仍为正） | ≈ +0.56（≈0） |
| 期望 R | **+0.629** | — |
| 胜率 | **16.3%**（94/578） | 16.2% |
| 平均赢 R / 平均亏 R | **+9.13 / −1.02** | — |
| 单 R 最大 / 最小 | **+33.56 / −2.57** | — |

**读法**：
1. **去掉最好的 10 笔（1.7% 的样本）后仍剩 76.27R** → **不是"归零"，而是剩余边缘仍有 +0.13R/笔**。
   → **我报告_011 §2 说的"去掉不到 1.8% 的单子 edge 归零"是按美元口径，过重了，我修正。**
2. 但**前 5 大单仍占 43.9%** → **尾部依赖依然存在且显著**（这是低胜率趋势跟随的固有形态）。
3. **平均赢 9.13R / 平均亏 1.02R、胜率 16.3%** → 期望 +0.629R，**这个 edge 在统计上是实的**。

**⚠️ 一个必须标注的口径缺陷**：`gold-100` 的 `risk_money` 中位仅 **1.63**、均值 **1.89** —— 这是**风险预算值**（300×0.05%），
**不是真实的手数×止损距离风险**。而 `pnl` 是真实盈亏。**所以该 R 被系统性放大。**
→ **结论**：§2 的 R 值**只能用于相对比较（集中度、胜率、盈亏比形态），不能当作绝对 R 用于年化换算**。
→ **要拿到干净的 R，需要你说过的那个修复**（把 `risk_money` 写成实际风险）。**这是我对你的请求的更新：不只是 `entry`，`risk_money` 也需要修。**

## 3. ★我的 DD 预期为什么错了（明确认错 + 机制）

我写："入金 600 应复现 PF 1.26 与 **DD ~19%**"。**实测 42.98%，我错了。**

**原因（我自己没想清楚就下了结论）**：
```
gold-100: 固定 0.01 手（RiskPct=0.05 使手数恒为地板）→ 风险金额固定 ≈ $1.9
          → 净值增长不放大仓位 → DD 19.15%
gold-102: RiskPct=1.0 → 每笔风险 = 当前净值 × 1%
          净值 600 → 2480（+1880）→ 手数同步增长 ~4 倍
          → 复利放大盈利【也放大亏损】→ DD 42.98%
```
**→ 这正是我自己在报告_009 §2.2 写过的结论（"真正决定 DD 的是 `InpRiskPct`，不是手数上限"），
我在报告_011 却忘了把同一条逻辑用到自己的预测上。这是同一个错误第四次出现：下了没推演到底的结论。**

**★因此"同时满足单笔风险≤1% + DD<20%"的可行组合只有一个方向**：
```
方案 A（可交付性优先）：固定手数 0.01 手 + 入金 600  → 单笔风险 ≈ $1.9 = 0.32%（<1% ✅）
                        预期 DD ≈ 19%（gold-100 实测）✅
                        代价：不享受复利（净利 +248 而非 +1880）
方案 B（收益优先）：RiskPct=1.0 + 入金 600 → 单笔风险 = 1.0%（正好 ✅）但 DD 43% ❌
→ ★我建议按【方案 A】，并在报告里注明"单笔风险 0.32%，实际留有 3 倍余量"
```
**注意**：方案 A 的 DD 19.15% 是在 300 本金上测的；**换到 600 本金、固定 0.01 手，R 序列完全不变，
但每笔风险占比减半 → DD 百分比会【更低】或持平**（DD% 由 R 序列与固定风险占比共同决定）。
→ **这是我可以给出的、同时满足两条硬约束的唯一口径，需实测确认（见 §6 的 gold-106）。**

**★这对交付是实质性的**：**真实交易的收益预期应取 gold-105 那一档（PF 1.26、年化 30.33%）**，

## 5. 关于 `gold-103` 年化 128.50%（我不再称其为"假象"）

我核算了年化公式：`ann = (1 + net/deposit)^(365/天数) − 1`
- gold-102：`(1+1880.86/600)^(365/3071.5)−1 = 37.43%` ✅ 与回填一致
- gold-103：`(1+768.37/600)^(365/365)−1 = 128.06%` ✅ 与回填一致

→ **公式没错，是"复合年化"。** 我此前称 gold-101 的 270.88% 为"口径假象"**用词不准**，应改为：
**"几何复合年化在收益高度不均匀时（大部分净利集中在少数离群单/后段）会远高于实际体验收益率，不适合作为交付指标。"**
→ **建议交付报告改用"净利 / 峰值净值"或"平均年净利 / 初始本金"**。
