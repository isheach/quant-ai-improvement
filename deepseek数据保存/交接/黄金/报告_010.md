## 3. 对 `gold-094` 固定手构造失败的诊断（我承认推演错了）

实测 **0 笔 / 10.3 秒**。我按源码 L415–480 重读，**错误出在 L420 之后的守卫**：

```
riskMoney = equity × InpRiskPct / 100 = 0
perLot    = stopDist × mpp        （正常，>0）
lot       = riskMoney / perLot    = 0
lot < vmin → 进入最小手分支 → 取 0.01 手
```
我漏看的是：**`riskMoney = 0` 时该函数在更早处即被判为不可行并 `return 0`（等价于放弃信号）**，
所以我推演的"取 0.01 手"路径从未到达。**这是我的推演错误，我承认。**

**修正构造（用你的备选方案①，我算过阈值）**：
```
让「理想手数 < 0.01」：InpRiskPct < 0.01 × perLot / equity × 100
训练期金价1250-2000、ATR(H1)≈$2-5 → perLot = 0.5×ATR×100 ≈ $100-250
→ 阈值 ≈ 0.01×100/300 = 0.33% … 0.01×250/300 = 0.83%
→ 取 InpRiskPct = 0.05%（远低于阈值，确保理想手数恒 <0.01）
+ InpMinLotMaxRiskPct = 100（放行最小手）→ 全部信号固定 0.01 手
```

## 4. 我的判断：**不建议现在推进滚动优化**（含新理由）

```
滚动优化要回答的是"参数是否随 regime 平滑漂移"
但 gold-093 的结果显示：这条策略的净利不来自"稳定 edge"，而来自 2020-2022 的 3 个事件里的 ~5 笔大赢
```
