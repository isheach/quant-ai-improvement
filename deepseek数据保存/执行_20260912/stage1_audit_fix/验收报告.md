### 1B · 出场流水（**本次主要修复**）
**旧实现三个缺陷**：
```
① entry 硬编码：FileWrite(..., DoubleToString(0.0,_Digits), ...)  → 审计 entry 永远是 0
② 全局单值风险：g_riskMoney / g_atrAtEntry 是全局变量 → 每个持仓没有独立状态
③ 重复记账：AuditRow()（主动平仓路径）与 RecordExitDeal()（OnTradeTransaction）
   为【同一次平仓】各写一行
```

**修复内容**：
```cpp
#define MAX_POS_TRACK 64
struct PosTrack { ulong pid; double entry, entryVol, riskMoney, atr, stopDist;
                  datetime entryTime; double closedVol; bool used; };
PosTrack g_pt[MAX_POS_TRACK];
```
1. **per-position 状态表**：开仓成功后按 `g_ticket` 登记 entry/vol/risk/atr/stopDist
2. **反查开仓腿**：`HistorySelectByPosition(pid)` → 对 `DEAL_ENTRY_IN` 行做**成交量加权均价**
3. **区分完整/部分平仓**：`vol < entryVol` 时按比例拆分 `risk_money`，并写 `close_type`
4. **新增两列**：`position_id`（对账用）、`close_type`（full/partial）
5. **去掉重复路径**：`ClosePosition()` 不再调 `AuditRow()`，只由 `RecordDealExit` 写
