### ★ 第二轮的核心结论（仍然成立）

1. **旧策略的"主发动机"（网格）其实是死的。** 用旧项目自己的 `stage1_full` 参数跑 2 年：**趋势单 484 笔，网格 0 笔**。原因：优化器把 `InpGridZ` 从设计默认 7000 **抬到 20000**（优化上边界），网格距变成 $20~25，在 60 分钟基线上几乎永不触发。**旧项目自以为在跑的"网格+趋势"混合体，实际一直只有趋势单腿在跑。**
   而且**就算把网格距调回来也不赚钱**：纯网格 6 个间距档，2 年净利 −72 ~ +43（4 档为负）。**根因：网格单均毛利润 $0.15 < 往返点差 $0.40。**
2. **真正有 edge 的是趋势层，且通过了冻结样本外验证。** 把 8 个被优化器架空的精度参数**锁回设计默认值**后：

   | 区间 | 净利 | PF | 权益回撤 | 净利/回撤 | 笔数 |
   |---|---:|---:|---:|---:|---:|
   | 训练 2023.01–2024.12 | **+76.56** | 1.34 | 10.94% | 1.26 | 102 |
   | **验证 2025.01–2026.06（冻结）** | **+242.89** | **1.67** | 11.04% | **2.73** | 103 |
   | 对照：`stage1_full` 原样 | +272.60 | 1.32 | 11.28% | 3.94 | 484 |
   | 对照：`stage1_full` 原样（验证） | **−44.12** | **0.58** | 15.15% | −0.54 | 45 |

   → **优化过的精度参数在训练集好看 3.6 倍，在验证集直接亏钱。** 铁律二第一次被实测证明。

**这一轮最重要的一句话**：**旧项目的问题不是"量纲"，而是"跑的根本不是那套策略"。先修机制，再谈量纲。**

## 2. 旧策略的精确解剖（一句话讲清楚）

```
基线 G_Baseline = 近 InpX_Minutes(40~60) 分钟收盘均价
  ├─ 空仓时：基线以 InpMoveB 的速度「朝现价追价」→ 缓慢趋势里不开单
  └─ 持仓时：基线朝「亏损方向」移动 Σ(coef_c × decay^i) → 把整篮止盈目标拉向现价
              ↑ 这就是「砍仓为什么有效」的机制根源

网格开仓：bid < 基线 − 网格距  → 开多（赌回归）
          网格距 = max(MinGridZ×价比, GridZ×价比×波动因子^变指数)，马丁：第 n 仓距离 ×1.4^n
整篮止盈：价格回到基线 → 平掉该方向全部网格单   ← 名义上的现金牛

趋势状态机（M5）：
  up_signal = RV%≥阈值 && 快EMA>慢EMA && 收盘突破前 N 根高点
  ├─ 禁逆势网格开新单
  ├─ 砍逆势网格（可选，默认 false）
  └─ 开独立顺势单（ATR 止损 + 移动止损，无固定止盈）← ★实际唯一在赚钱的部分

硬风控：风险 L2/L3/L4、last_order_stop、cutoff_line_stop、周末保护、加仓延迟、冷静期
eva028 阶段1 新增：整篮金额止损、日损、净值高水位回撤锁
```

**★ v2 的关键修正**：`stage1_full` 参数下，**网格分支 2 年 0 成交**。所以"基线追价 + 马丁网格"这套机制**在当前参数下完全没被激活**。实际在跑的是**趋势单腿**。

### 3.2 tick_value 的口径取舍（必须知道）

EA 唯一用它的是末单止损换算 `loss_dist = InpLastOrderLossPerLot × tick_size / tick_value`。
真实品种的 tick_value 随现价变化（XAUUSDm 在 4385 价 ≈ 0.4385），但**自定义品种只能存一个常量**。44 个月金价从 1804 → 5595（3.1 倍），只能选一个口径。
**本项目选：按参考价 4000 校准 → tick_value = 400.0。** 理由：这让"每手 $800 亏损"折算成约 4.8% 价格，正是旧项目当初的设计意图；而且网格距离本身按 `price/InpRefPrice` 缩放，整篮止损触发位置在各价位保持自洽（= **固定美元风控**，对 500 本金是正确口径）。

> ⚠️ **如果改用真实符号 XAUUSDm 回测**（拿到真实 tick_value ≈ 0.4385），
> 末单止损距离会变成 `800 × 0.001 / 0.4385 ≈ 1.82` 美元，而不是自定义品种下的 `800 × 0.001 / 400 = 0.002` 美元。
> **两者差异巨大 —— 跨数据源比较结果时必须先对齐这个口径。**

### 3.3 网格在真实数据上不赚钱（★推翻 v1 的"网格是地基"）

纯网格模式（`InpEnableStateMachine=false`），训练集 2023-2024：

| `InpGridZ`/地板 | 净利 | 笔数 | 止盈侧合计 | 灾难笔 |
|---:|---:|---:|---:|---|
| 1000 / 500 | −72.55 | 308 | +49（280 笔） | cutoff −72 |
| 2000 / 1000 | −63.02 | 322 | +23（304 笔） | 日损 −78 |
| 3000 / 1500 | −66.17 | 215 | +29（201 笔） | 日损 −78 |
| 5000 / 2500 | −52.69 | 65 | +33（50 笔） | 日损 −78 |
| 7000 / 2000 | −1.00 | 46 | +41（41 笔） | 日损 −42 |
| 10000 / 5000 | +43.28 | 7 | +43（7 笔） | 无 |

**判读**：止盈侧永远为正（毛 edge 真实存在），**但被灾难笔吃光**。
**根因（量纲）**：单均毛利润 ≈ $0.15，**往返点差 = 200 点 × 2 × $0.001 = $0.40**。**毛利润比点差还小。**
→ 网格不是"edge 变弱"，是**根本没覆盖交易成本**。在 500 本金 + 0.01 手下限 + 现实点差下，**网格无解**。

### 3.5 鲁棒性敏感度（区分"平台"与"针尖"）

以锁定基座为底，每次只动一个参数（训练集）：

- ✅ **平台**（平滑、稳健）：突破窗口 20~60（净利 65~77）、趋势 RV 阈值 0.015~0.025（单调 92→47）、慢 EMA 40~100（74~77）、趋势止损 2.5~5.0（76~79）、移动止损 4.5（76）。
- ⚠️ **针尖**（不稳健，两区间符号甚至相反）：
  - **快 EMA**：10→52.7，15→76.6，**30→−23.1**
  - **确认根数**：1→132.8（训练）但**验证 −64.5**；3→基座；**5→−6.4**
  - **Vol-Gate**：训练期开=76.6/关=56.0（有用）；**验证期开=242.9/关=302.7（有害）**

### 3.6 风控层现在是"哑的"

永久锁 15% / 25% / 40% / 关 —— **四者结果完全相同**；开日损 / 关日损 —— **完全相同**。
原因：锁定基座最大权益回撤只有 10.94%，**从未碰到 15% 的锁**。
→ **当前回撤是策略本身限制的，不是风控限制的。** 这意味着**回撤预算（用户接受 30~40%）还空着 3 倍**。

### 3.7 牛市 beta 排除

验证期（2025-2026 金价 2600 → 5600 单边走强）全关策略 → **0 笔成交、0 盈亏**。
→ **收益 100% 来自策略信号，不是行情漂移。**

## 5. 我确立的方法论纪律（v2 更新）

1. **精度参数永不进优化空间。** 定义在 `run\mt5exp.py` 的 `LOCKED_BASE`。**§3.4 是实测证明。**
2. **任何"机制"必须用 `exit_reason` 计数验证它真的触发了。** 网格 0 笔就是这么发现的。
3. **实验必须单变量 + 有反事实。** 编排器强制"锁定基座 + 一个覆盖项"。
4. **训练/验证/测试三段，验证只用一次。** 训练 2023-2024，验证 2025-2026。**已用掉一次验证。**
5. **用百分比/ATR 表达所有风险量，不用点数、不用绝对美元。**
6. **回测固定手数、不开复利。**
7. **★新增：区分"平台"与"针尖"。** 每个定案参数都要做 ±1 格敏感度扫描（§3.5）。"针尖"上的最优点一律不接受。
8. **★新增：训练集数字比锁定版高很多时，要怀疑而不是高兴。**
9. **发现自己的分析脚本有 bug 时，明确作废那段结论并注明。**
