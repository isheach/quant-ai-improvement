## 零、结论先行

### ✅ 正确的导出工具是 `eva008_TickDataExporterEA.mq5`（EA + 策略测试器）

位置：`旧量化策略\2代数据\eva008_TickDataExporterEA.mq5`（v3.00，298 行）

**它文件头自己就写明了为什么要这么做**：
> 实时图表上的脚本读的是「终端实时历史缓存」，深层历史不自动拉满，所以只看到近几个月；
> 而「策略测试器」会为回测区间装载**完整历史**（2014→今），EA 在测试器里能看到每一个 tick /
> 每一根 bar，并且**可以写文件**。因此把导出器做成 EA，在测试器里「收一个写一个」，即可拿到完整数据。

**我实测确认它工作正常**（三条路线里唯一"设计正确"的）：

| 项 | 结果 |
|---|---|
| 编译 | `0 errors, 0 warnings` |
| `[TesterInputs]` 注入 | ✅ **有效**（它是 EA，不是 Script —— 这正是 eva005 失败的原因） |
| 2026.09.08~09.10 | `ticks=11024, bars=2757`，CSV + meta.json 输出正常 |
| 2023.01.05~01.08 | `ticks=10780`，**能取到 2023 年的数据** |

### ❌ 但**真实历史 tick 拿不到** —— 铁证

用 eva008 + `Model=1`（"Every tick based on real ticks"）导出的 tick，**全是合成的**：

| 判据 | 实测值 | 真实 tick 应长什么样 |
|---|---|---|
| **时间间隔** | **固定 20000 ms（偶有 19000）** | 毫秒级不规则、有密集簇 |
| `volume` | **恒为 0** | 有真实成交量 |
| `volume_real` | 恒为 0.00 | 非 0 |
| `flags` | **恒为 14** | 变化（bid/ask/last 各类） |
| `spread_pts` | **整段恒定**（2026 段 260、2023 段 200） | 随行情波动 |

**我在 2023 年、2026-09-08、2026-09-09~11 三个窗口都测了，签名完全一致 → 全是合成 tick。**

> 2023 段 `spread=200`、2026 段 `spread=260`，说明 MT5 是用 **M1 OHLC + 当期记录点差**插值生成 tick，
> **不是真实成交数据**。

**唯一有真实 tick 的地方**：终端**实时缓存** `bases\<server>\ticks\`。
实测 `XAUUSDm\202609.tkc` 24.1 MB、`202608.tkc` 5.15 MB（8 月只覆盖部分天）。
即 **真实 tick 只有最近约 1~2 天到 1~2 周**，而且**脚本读得到、测试器反而读不到**（签名已证明）。

### 📌 最终结论

1. **bar（M1/M5）可以拿到很长历史** → eva001（已跑完 149 个月）或 eva008，两者都行。
2. **真实 tick 只有最近 1~2 天/周**（在实时缓存里），**历史 tick 无法下载**。
3. **任何历史区间的 tick 都是 MT5 合成的**，不要当真实成交数据用。
   若研究确实需要 tick 精度，只能**从现在起实时采集并累积**（唯一可行路线）。

## 三、要接的活 + 正确做法

### 3.1 补 BTCUSDm / USDJPYm 的 bar（推荐 eva008，参数可注入）

```ini
[Tester]
Expert=eva008\eva008_TickDataExporterEA
Symbol=BTCUSDm          ; ← 换品种即可
Period=M1
Model=2                 ; 只导 bar：够用且快
Optimization=0
FromDate=2014.01.01
ToDate=2026.12.31
ShutdownTerminal=1
[TesterInputs]
InpExportTicks=false
InpExportM1=true
InpExportM5=true
InpOutRoot=eva008_data
InpUseCommonFiles=true
```
模板：`deepseek数据保存\mql5\config\eva008_recent.ini`（照它改）
⚠️ **如实报告每个品种的实际覆盖起点** —— 不同品种券商给的深度不同。

### 3.2 多周期
`InpExportM15=true`（eva008 支持 M1/M5/M15）。H1/D1 要自己加一行。

### 3.3 需要 tick → 做实时累积器（唯一可行路线）

既然历史 tick 不存在，**只能从现在开始采集**：
- 写一个**常驻 EA** 挂实时图表（不是测试器），在 `OnTick()` 里把 tick 追加写 CSV，按天/月轮转。
  **放着不动就越攒越多。**
- 或定时用 `CopyTicksRange` 拉"最近 N 天"（实时缓存里有）并归档。
- ⚠️ 终端未登录/未运行时不会采集，会有空洞 → **必须诚实标注覆盖区间**。

### 3.4 整理数据仓库

`data\` 下现有三套，建议只保留后两套：
- `real\`（我用**有缺陷**方法导的，部分结论已作废）→ 加 `DEPRECATED.md` 或删除
- `eva001_export\`（可信 bar）
- `eva008_export\`（样例 + tick 签名证据）
