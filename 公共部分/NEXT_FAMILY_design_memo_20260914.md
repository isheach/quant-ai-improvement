## 0. 先说一条必须记录的实证结论

JSB30 的失败给出了一个**结构性的、可复用的量化判断**，比"又失败了一个 family"更重要：

```
JSB30 V1 实测（1143 笔、6.4 年、成交跨度 99.8%）：
   胜率      = 422 / 1143 = 36.9%
   平均盈利  = +4.66 USD
   平均亏损  = −3.25 USD
   实际盈亏比 = 1.43
   → 期望 = 0.369 × 1.43 − 0.631 × 1.0 = −0.10 R/笔

★TP 设为 1.5R，但实际盈亏比只有 1.43（达不到设计值），
  而突破类结构的胜率只有 36.9%。
  ⇒ 这是【结构性负期望】，不是参数没调好。
  ⇒ 大样本 + 99.8% 跨度 + 三变体一致为负 ⇒ 统计上是真负 edge。
```

**★由此得到的、对下一 family 的硬约束**：

```
如果继续做【低胜率 / 高盈亏比】的结构（趋势突破、时段突破），
在 500 USD 账户 + 11 点固定点差 + 0.01 手地板的约束下，
需要胜率×盈亏比 > 1，而上述两条已否证的线都在 0.5~0.53 区间。
→ ★下一 family 必须换到【高胜率 / 小盈亏比】的信息结构，
  否则会在同一个数学约束下再失败一次。
```

**★同时也必须诚实登记一条项目级观察**：
```
本项目累计约 8,000+ 次回测、三条标的、六个结构族（趋势突破 / 均值回归 / 网格 /
时段突破 / 滚动优化 / 逆势 M30），目前【没有任何一个产生可交付的正期望】。
这构成一个越来越强的先验：在 $500 资金 + 零售点差 + 0.01 手地板的约束下，
简单规则型策略达到正期望的难度可能极高。
→ 下一 family 的默认预期应当是【再被否证】，而不是"这次会成"。
```

## 2. 下一 family：`XAF30`（Cross-Asset Filtered breakout on M30）

### 2.1 为什么选"跨品种信息源"这个维度

```
★本项目【从未使用】过第二个品种作为信息源。
  所有已否证 family 的信号都只来自【单一品种自己的价格】。
  → 这是唯一一个"既未覆盖、又能在 $500 下单标的执行"的结构维度：
     用另一个品种做【过滤】，但仍只交易一个品种 → 资金需求不变。
```

### 2.2 结构定义

```
名称    : XAF30
品种    : 交易 USDJPYm（真实券商品种）
信息源  : XAUUSDm（黄金）作为【美元方向的一致/背离信号】
周期    : M30
仓位    : 单仓；每个 UTC 日最多一笔
时段    : 不做时段突破。仅使用【信号 bar 收盘时刻】触发，全天可入场
退出    : ★固定 SL = 1.0×ATR14(M30)，固定 TP = 0.8R（高胜率/小盈亏比）
          最长持仓 12 根 M30；不做移动止损
入场条件: 以下三条【同时】满足
   ① USDJPYm 的 M30 收盘价相对 EMA(48) 的偏离 >= 1.5 × 近 48 根 M30 的标准差
   ② 黄金在该 bar 的 M30 涨跌方向与 USDJPYm 相反
      （黄金涨 → 美元弱 → 做多 USDJPY 需黄金跌，故要求两者反向）
   ③ 该 bar 的 ATR14 处于近 500 根 M30 的 ATR 分位 [P20, P80] 内（避开极端波动）
★方向：只做与①的偏离方向相反的一侧（均值回归）
```

### 2.3 与已否证 family 的结构差异

| 维度 | 已否证（最有代表性的 MR30 / JSB30） | **XAF30** |
|---|---|---|
| 信息源 | **单一品种自身价格** | **★USDJPYm + XAUUSDm 两个品种的关系** |
| 信号类型 | 突破 / 仅价格偏离 | **价格偏离 + 跨品种方向一致性** |
| 盈亏比设计 | 1.5R / 2.5R（低胜率高盈亏比） | **0.8R（★高胜率小盈亏比）** |
| 入场时段 | 固定时段窗 | **全天，由信号触发** |
| 持仓上限 | 16 / 24 根 M30 | 12 根 M30 |
| 过滤器 | ATR 波动状态 | **跨品种方向一致性 + ATR 分位**（双过滤） |

**★核心假设（可证伪）**：
```
当 USDJPY 相对均值大幅偏离，而黄金【没有】给出同向确认时，
该偏离更可能是【流动性/噪声】而非【美元基本面重定价】→ 更可能回归。
→ 该假设若为真，XAF30 的胜率应显著高于同类单品种均值回归；
  若为假，XAF30 会与 JPY 均值回归线一样失败（即"跨品种信息无用"）。
```

### 2.4 三个预注册变体（≤3，运行后不得增删）

| 变体 | 唯一差异 |
|---|---|
| `XAF30_V1` | 基准：偏离阈值 1.5σ，跨品种过滤**开启**，TP 0.8R |
| `XAF30_V2` | **关闭跨品种过滤**（只保留 ①③）→ ★对照组，用于检验跨品种信息是否真有贡献 |
| `XAF30_V3` | 偏离阈值 2.0σ（更严格），跨品种过滤开启，TP 0.8R |

（这正是本项目方法论纪律 B 的应用 —— 先设计同口径控制组再谈 edge）。

## 3. 失败机制（先写清，避免事后解释）

```
① 跨品种信息无用：V1 ≈ V2（两者都与单品种均值回归一致地失败）
   → 最可能的失败模式；已否证的 JPY 均值回归线支持这一预期
② 点差吃掉边际：11 点固定点差 = 0.011 价格
   若 TP 只有 0.8R 且 R = 1.0×ATR(M30)，M30 的 ATR 量级若为 ~0.15 → TP ≈ 0.12 价格
   点差占 TP 的 9% → 可接受；但若 ATR 更小则点差占比急升
   ★必须在 preflight 实测 ATR 中位数与 spread/TP 比值
③ 高胜率不足以补偿 0.8R：需要胜率 > 55.6% 才能保本（1/(1+0.8)）
   → 若实测胜率只有 48~52%，则仍是负期望
④ 尾单依赖反转：高胜率小盈亏比结构通常【亏在少数大亏单】（止损滑点/跳空）
   → 去前 10 大【亏损单】后若转正，说明是被少数极端亏损拖垮
   ★注意：这与既往"去前 10 大盈利单"的检验方向相反，本 family 必须两个方向都做
⑤ 最小手地板：500 USD / 0.01 手 / 1.0×ATR 止损 → 实际风险可能超预算而被拒单
   → 必须统计 rej_risk 比例；若拒单率 > 30% 则结构在 500 USD 下不可执行
⑥ 跨品种数据不同步：黄金与日元的 M30 bar 时间戳必须严格对齐
   → 若某一品种在某些 bar 缺失，会造成虚假的"背离"信号
   ★preflight 必须验证两品种 M30 bar 时间戳的重合率
```
