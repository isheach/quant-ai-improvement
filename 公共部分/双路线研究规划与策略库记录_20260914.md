# 双路线研究规划与策略库记录（2026-09-14）

> 性质：后续研究方向记录 / strategy research roadmap。
> 
> 本文件用于记录当前已经形成的研究共识，不替代也不修改现有 XAMR30、JSB30、MR30 等已经冻结或关闭的 Source-of-Truth、预注册文件与历史证据。
> 
> 研究用途仅限历史回测与方法研究，不授权实盘或真实资金交易。

---

## 1. 当前总体思路

项目后续不再把任何一个单一 EA 当成“必须救活”的策略。

现有与后续策略统一视为一个 **策略库（Strategy Library）**。每个策略只是针对某类市场状态的候选“专家模型”。

当某个方法在全周期上跑不通时，后续允许沿以下顺序研究：

1. 先判断失败是“模型本身无 edge”，还是“只在某些市场状态有效”；
2. 如果模型在明确的局部 regime 中仍有稳定 edge，可保留为专家模型；
3. 如果模型在主要市场状态下都无稳定 edge，则停止继续细调，切换到其他策略家族；
4. 如果多个策略在不同环境下各有优势，则研究由上层状态识别器进行切换；
5. 只有在切换式组合已经证实有效后，才进一步研究多模型同时投票/确认类组合；
6. 不允许根据已看到的未来收益，事后把不同年份、月份或窗口拼成漂亮组合。

核心目标从“寻找一个永远有效的万能 EA”调整为：

> **建立多个擅长不同市场环境的专家策略，并研究什么时候该让哪个策略工作、什么时候应该全部停止交易。**

# 2. 路线 A：USDJPY + XAUUSD 跨资产参考

当前路线 A 为 **XAMR30**。

## 2.1 研究对象

- 实际交易标的：`USDJPYm`
- 辅助信息标的：`XAUUSDm`
- 周期：M30
- 黄金只提供信息，不交易黄金。

## 2.2 核心假设

USDJPY 出现短期过度偏离时可能发生均值回归；黄金的同时间走势可能提供额外确认信息。

因此主要比较：

- V1：USDJPY 均值回归 + 黄金方向确认
- V2：USDJPY 均值回归，不使用黄金方向过滤（控制组）
- V3：更严格 USDJPY 偏离阈值 + 黄金方向确认

这条路线需要回答两个问题：

1. USDJPY M30 均值回归本身是否存在可重复 edge；
2. XAUUSD 的跨资产信息是否显著改善 USDJPY 信号。

## 2.3 当前状态

继续按照现有 XAMR30 预注册和工程验证流程推进，不因本文件新增的路线 B 而修改已冻结参数或实验口径。

路线 A 的价值是验证一个具体、低自由度、可证伪的跨资产交易假设。

# 3. 路线 B：策略库 + 市场状态识别 + 动态模型选择

路线 B 来自新的研究想法：

> 不是假设一个策略始终有效，而是持续判断“当前市场是否仍然像该策略训练/验证时适用的市场”。
>
> 市场状态匹配时允许策略交易；状态明显漂移、策略表现异常恶化或进入未知状态时，停止该策略，必要时切换到其他更适合的专家策略。

这条路线的重点不是继续滚动挑一组参数，而是研究：

> **什么市场环境适合什么模型？**

最终形式可以理解为：

`Market Regime / Drift Detection -> Model Selection -> Trading Expert -> Risk Control`

# 4. 当前策略库

以下为目前已经实际研究过、实现过或形成明确实验家族的主要策略类型。

## 4.1 Expert G：Grid / Range

### 类型
网格 / 分层均值回归 / 区间策略。

### 历史基础
包括较长历史的 `VolumetricPulseGrid` 系列、`GoldGridCoreV1`，以及后续 USDJPY 滚动网格实验。

### 基本逻辑
价格偏离基线后开第一层；继续偏离时按 ATR/层距增加仓位层；价格重新回归基线或持仓成本附近时退出。

### 理论适用环境
- 横盘
- 震荡
- 均值稳定
- 缺少持续单边趋势

### 主要风险
- 单边趋势持续扩张
- 多层仓位累积
- 小账户最小手数地板
- 交易成本累积

### 当前定位
历史上全周期未形成稳定可交付 edge，但可以作为未来的 **震荡专家候选**，前提是上层状态识别器能够事前可靠区分震荡与趋势。

---

## 4.2 Expert T：Trend

### 类型
趋势跟随。

### 历史基础
- USDJPY `dsh_TrendCore`
- BTC 趋势/Donchian breakout + 大周期方向过滤 + trailing stop 类结构

### 基本逻辑
顺着已经形成的方向开仓，让趋势继续发展，并通过 trailing stop / Chandelier 等方式保留大趋势尾部收益。

### 理论适用环境
- 持续趋势
- 大级别方向清晰
- 波动扩张且有延续性

### 主要风险
- 震荡反复止损
- 利润高度依赖极少数大趋势单
- 趋势结束阶段回吐

### 当前定位
历史结果显示全周期稳定性不足，但很适合作为未来的 **强趋势专家候选**。

---

## 4.3 Expert B：Breakout

### 类型
突破 / 波动扩张。

### 历史基础
代表性实验：`JSB30` USDJPY M30 session breakout。

### 基本逻辑
先形成价格区间或波动压缩区，随后价格突破区间时顺势交易。

### 理论适用环境
- 波动由收缩转扩张
- 市场即将进入方向性阶段
- session 切换产生新信息

### 主要风险
- 假突破
- 震荡市频繁反复
- 突破后没有延续

### 当前定位
JSB30 全周期 TRAIN 已失败并关闭，不再对原版本事后调参；但“突破”这个策略家族仍可以作为未来 **Breakout Expert** 的研究基础。

---

## 4.4 Expert MR：Mean Reversion

### 类型
单笔反转 / 均值回归。

### 历史基础
- `dsh_JPYRev`
- `MR30`
- 当前 XAMR30 的 USDJPY 主体也属于均值回归大类

### 基本逻辑
当价格相对均值、EMA 或标准化偏离达到极端水平时，反向交易，预期价格回归正常区域。

### 理论适用环境
- 横盘
- 震荡
- 短期过冲
- 均值结构仍稳定

### 主要风险
- 强趋势中不断逆势
- regime 改变后“旧均值”失效
- 连续假回归信号

### 当前定位
历史单模型结果总体不理想，但它天然适合作为未来 **震荡 / 过冲回归专家**。

---

## 4.5 Expert XA：Cross-Asset

### 类型
跨资产信息策略。

### 当前代表
`XAMR30`。

### 基本逻辑
USDJPY 产生均值回归候选信号后，使用同一 M30 timestamp 的 XAUUSD 信息判断该信号是否值得执行。

### 理论适用环境
- USDJPY / XAUUSD 的关系仍处于训练时见过的 regime
- 跨资产信息稳定
- 单品种信号本身存在一定基础 edge

### 主要风险
- 跨资产关系结构性改变
- XAU/JPY session 不完全一致
- 相关关系在危机或政策阶段突变

### 当前定位
路线 A 正在正式研究；如果通过，未来可直接进入路线 B 作为跨资产专家。

# 5. 上层 Regime Controller / Model Selector

路线 B 真正的新研究重点是上层控制器，而不是再发明更多底层 EA。

上层控制器不直接产生交易方向，主要回答：

1. 当前市场是什么状态？
2. 当前状态与某个专家模型的训练有效区间有多相似？
3. 当前允许哪些专家工作？
4. 当前是否应该全部停止交易？

初步状态可以从简单版本开始，例如：

- `RANGE`
- `TREND`
- `BREAKOUT_READY`
- `HIGH_VOL`
- `LOW_VOL`
- `CROSS_ASSET_NORMAL`
- `CROSS_ASSET_DRIFT`
- `UNKNOWN / OUT_OF_DISTRIBUTION`

示例调度：

- RANGE -> Grid / MR 可工作
- TREND -> Trend 可工作
- BREAKOUT_READY -> Breakout 可工作
- CROSS_ASSET_NORMAL -> XAMR 可工作
- UNKNOWN / DRIFT -> 全部停止新开仓

第一版优先使用简单、可解释、低自由度的 ON/OFF 控制，而不是立刻引入复杂多模型权重。

# 6. Drift Detection：什么时候停止一个模型

路线 B 必须同时监控两类漂移。

## 6.1 Market Drift

不看策略盈亏，只判断当前市场是否已经脱离模型训练时见过的状态。

候选变量包括：

- ATR / realized volatility
- trend strength
- z-score / residual distribution
- spread
- session structure
- USDJPY/XAU correlation 或 cross-asset relation
- signal frequency
- range / breakout characteristics

后续可从 percentile / distance-based 方法起步，再逐步研究 Mahalanobis distance、one-class model、change-point detection 等。

## 6.2 Performance Drift

监控策略本身是否出现异常失效。

不能只用“连续亏 3 笔就停止”这类容易过拟合的规则。

更合理的候选统计包括：

- rolling expectancy (R)
- rolling PF
- win rate
- average win/loss
- drawdown
- loss distribution
- 与 TRAIN bootstrap / historical distribution 的偏离

后续可以研究 Page-Hinkley、ADWIN、CUSUM 或其他 sequential change-detection 方法。

原则：停止规则也必须在 TRAIN 内开发和冻结，不能看到 VALID/OOS 后再改阈值。

# 7. 多策略组合的研究顺序

组合研究分为三个等级，必须按顺序推进。

## Level 0：单策略基线

每个专家单独测试，建立其：

- 全周期表现
- 不同年份表现
- 不同 regime 表现
- 主要失败环境

目的不是强行要求每个专家全周期赚钱，而是建立“能力地图”。

## Level 1：切换式组合（优先）

由上层状态识别器选择一个或少量适用专家。

例如：

`Range -> MR`

`Trend -> Trend Expert`

`Breakout Ready -> Breakout`

`Unknown -> Cash / No Trade`

这是当前最优先的组合方向。

## Level 2：多模型确认 / 投票

只有 Level 1 证明有增益后，才研究：

- 两个模型同向才下单
- 多数投票
- confidence weighting
- risk allocation by model confidence

这一级自由度高、过拟合风险大，必须晚于切换式组合。

# 8. 当一个方法失败时的处理规则

以后不再采用“失败 -> 继续加很多参数直到变好”的默认做法。

建议固定处理顺序：

### A. 首先判断是否完全无 edge

如果策略在主要市场状态下均：

- expectancy <= 0
- PF <= 1
- 无稳定局部优势

则关闭该具体模型，不继续细调。

### B. 如果只在特定 regime 有 edge

保留为专家模型候选，并明确记录：

- 适用状态
- 禁用状态
- 状态识别指标
- 样本数
- 是否经过独立 VALID

### C. 如果一个策略家族确实不行

切换到其他策略家族，而不是继续围绕原模型增加过滤器。

### D. 如果多个专家互补

先做预注册的切换式组合，再考虑同时组合。

# 9. 防止“组合后过拟合”的硬原则

路线 B 最大风险是：看完历史后，永远能解释“当时应该用哪个模型”。

因此必须禁止以下做法：

- 看完 2020 收益后规定“2020 应该用 Trend”
- 看完 2021 收益后规定“2021 应该用 Grid”
- 根据 VALID / OOS 结果修改 regime 阈值
- 穷举大量 controller 参数后只报告最好的一组
- 按年份、月份、星期事后拼接模型
- 用未来收益作为当前 regime 标签

正确问题必须始终是：

> **在当时那个时间点，只使用此前可获得的数据，能否判断当前应该启用哪个专家？**

所有状态判断必须遵守 causal / no-lookahead 原则。

# 10. 未来建议的研究架构

最终系统可以抽象为：

```text
Market Data
   |
   v
Regime / Drift Detector
   |
   +--> RANGE ------------> Grid / Mean Reversion Expert
   |
   +--> TREND ------------> Trend Expert
   |
   +--> BREAKOUT_READY ----> Breakout Expert
   |
   +--> CROSS_ASSET_OK ----> XAMR Expert
   |
   +--> UNKNOWN / DRIFT ---> NO TRADE

                     |
                     v
               Risk Controller
                     |
                     v
                  Execution
```

后续如果需要机器学习，优先把 ML 用在“状态识别 / 模型选择 / OOD 判断”上，而不是一开始直接替代所有底层交易逻辑。

# 12. 当前研究共识

项目后续正式保留两条主线：

## Route A

**USDJPY 均值回归 + XAUUSD 跨资产信息。**

目标：验证黄金信息能否改善 USDJPY 的可交易 edge。

## Route B

**多专家策略库 + 市场状态识别 + 漂移检测 + 动态模型选择。**

目标：不要求任何一个策略永久有效，而是让不同策略只在自己适用的市场环境工作；当市场与所有已知状态都不匹配时，允许系统主动不交易。

最终研究思想：

> **底层模型负责“怎么交易”；上层模型负责“现在谁应该交易，以及现在是否应该交易”。**

这两条路线可以并行存在，但实验数据、预注册与 VALID/OOS 纪律必须相互隔离，避免新想法反向污染已经开始的历史实验。
