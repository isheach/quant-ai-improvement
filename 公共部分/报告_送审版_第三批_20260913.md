### 5.2 设计动机（直接来自 C1 的失败模式）

```

    valid 净利  +187.48 → 去前10大单 −247.67（前10占 232.1%）
→ 盈利由极少数大趋势尾单承担（与黄金线同一结构问题）

★ 因此 MR30 的核心检验目标是「edge 是否【不依赖尾单】」，
   而不是「能否做到更高年化」——手段是【有上限的收益/时间退出】。
```

