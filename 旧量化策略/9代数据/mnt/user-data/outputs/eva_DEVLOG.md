## 3. 回撤变大要不要紧（回答你的问题 2）

**有两种回撤，这次朝相反方向变**（同口径新旧对比，起始 $400）：

| | 旧 eva002 | eva011 |
|---|---|---|
| 净利 | +4316 | +1450 |
| **已实现回撤(余额)** | −245（−5.9%）| **−360（−17.5%）** |
| 回撤 / 净利 | 5.7% | **24.8%** |
| **浮亏峰值(保证金风险)** | **$338.9** | **$200.1** |
| 最低权益 | $346 | $375 |

- 你看到的"回撤变大" = **已实现(余额)回撤**：−245→−360，占净利比 5.7%→24.8%。
- 但**真正会爆仓的浮亏(权益)回撤反而降了**：$339→$200，地板 $346→$375。
- **为什么一升一降**：旧版几乎不砍亏损单，把它**浮在水里硬扛**（到 $339=旧账户 85%）等回归 → 余额平滑、已实现回撤小；新版会砍（179 次趋势平 + 3 次熔断），砍单变成**已实现亏损**显示出来 → 余额回撤变大，但浮亏被压住。
- **结论**：
  - 对"会不会爆仓"：eva011 **更安全**（浮亏与地板都更好）；−360 是从盈利高点(~$2057)回吐，不是亏进本金。
  - 对"赚钱质量"：**变差**——净利掉 66%（4316→1450）比回撤降得更多。**旧版那 +4316 里很大一块本就是"扛 $339 浮亏赌回归"赚来的；去掉这个险，利润也跟着没了**（马丁本质）。
  - 即：这种"已实现回撤变大"不危险，但它**暴露了去险后边缘很薄**（样本外微亏）。

## 4. 两个方案详解（回答你的问题 1）

**支撑数据（eva011 按波动档位）**：

| 波动档位 | 笔数 | 净利 | PF |
|---|---|---|---|
| 高波动 regime 2 | 117 | **+1070** | **1.94** |
| 中波动 regime 1 | 667 | +346 | 1.15 |
| 低波动 regime 0 | 48 | +35 | 1.14 |

**74% 利润来自高波动档（仅占 14% 成交）；最赚 2 个月（2026-02/03）占 90% 净利。**

### 方案 A：高波动收割器（regime harvester）
- **做什么**：只在高波动时开仓，其余时间空仓等待。
- **怎么做**：用现成开关 `InpRegimeMode`（档位模式）。现在 = `REGIME_MODE_AUTO`（全开）；改 `REGIME_MODE_FORCE_HIGH`（仅高波动）或 `REGIME_MODE_MID_HIGH`（中+高）。纯参数，不重编译。
- **依据**：边缘高度集中在高波动档（PF 1.94），中低档是稀释。砍掉后成交 832→~117，回测更快，每笔有真边缘。
- **代价**：成交极少、**大段空仓**等行情；依赖"高波动月重复出现"。没有大行情时就一直空着（不亏也不赚）。本质"等暴风雨→收割→平时歇"。

### 方案 B：walk-forward 选稳健参数（继续连续交易）
- **做什么**：仍全时段交易，但**换选参数的方法**抗过拟合。
- **怎么做**（滚动前推验证）：
  1. 把 2017-05→2026 切滚动窗口（如训练 12 月 → 测试后 3 月，向前滚 3 月，重复）；
  2. 每窗口训练段优化、测试段验证，记**测试段**表现；
  3. 挑"**多个测试段都还行**"的参数，而非"单窗口净利最高"（后者就是你这次"训练最优要慢趋势、测试最优要快趋势"的过拟合）；
  4. 邻域检查：选"周围也都不错"的高原，不选孤立尖峰。
- **依据**：解决"换窗口最优参数就翻脸"。
- **代价**：计算量大很多；诚实预期是"稳健参数样本内利润更低、样本外更稳"。若连 walk-forward 都找不到样本外为正的参数，等于宣判"连续交易没有可靠边缘"——这也是有价值的结论。

### 关系与建议
- A = 承认边缘只在高波动、就只做那段；B = 用严格验证抢救连续交易。可结合（在高波动档**之内**再 walk-forward）。
- 就你的数据（90% 利润在 2 个月）看，**A 更贴合边缘真实位置**；B 是检验"能否更通用"的严格手段。
