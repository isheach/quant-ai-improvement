## 3. 重设计方案（对准用户点 4 的结构性问题）

### R1：波动率度量改"对数收益百分比波动 + 固定百分比阈值"
- **现状问题**（源码确认）：`InpUseFixedLongRV` + `InpFixedLongRVPoints=50` + `InpFixedLongRVRefPrice`（固定长周期RV，再按 当前价/参照价 缩放），档位用 `InpRVRatio_*` 四个比值阈值（`CalcRealizedVolPoints` 返回**绝对点数**）。
  - 固定值靠手工观察 → 老数据（黄金 $1k）失效；
  - 价格缩放是"波动随价位线性"的粗代理；
  - 若改回滚动长周期RV，持续高波动时 \(RV_{short}/RV_{long}\to1\) 信号被洗白。
- **改法**：
  - RV 从"绝对点数"→**对数收益 \(r_t=\ln(P_t/P_{t-1})\) 的标准差（百分比波动）**：与价位无关，删掉 `InpFixedLongRVRefPrice` 缩放与 `InpFixedLongRVPoints` 固定值；
  - 判档用**绝对百分比阈值**（如短周期年化波动 > x%）而非比值：持续高波动不洗白、跨年代稳定；
  - `InpUseFixedLongRV / InpFixedLongRVPoints / InpFixedLongRVRefPrice` + 四个 `InpRVRatio_*` → 被 **2–3 个百分比阈值**替代。

### R2：三套硬编码参数 → 按波动率连续缩放的少数系数
- **现状问题**：低/中/高各一套 `InpBaseGridZ`(100/350/700)、`InpGridExpCoef`(1.1/1.4/1.8)、`AvgVolumePerMin` 等，各自寻参 → **三组互不相关、无递进、易过拟合**。
- **改法**：
  - 网格间距 \(= k_{grid}\times\) 当前波动率；止盈距离 \(= r_{tp}\times\) 网格间距。
  - 网格随波动**连续变宽/变窄**（高波动自动宽）→ 这就是缺失的"递进"，且物理、连续；
  - 一个 \(k_{grid}\) 取代三个 `BaseGridZ`；一个 \(r_{tp}\) 取代三套止盈；`GridExpCoef` 留一个共享值；
  - `multiplier_a`（现来自 `AvgVolumePerMin` 比值，又一套手工档）→ 简化为 1 个上限或并入波动缩放；
  - 离散三档不再承载参数，只留一个"**波动率低于下限不开仓**"的开关阈值（顺带实现 A 路线的"低波动空仓"）。

### 参数量对比（自由旋钮，约数）
| 模块 | 现在 | 重设计后 |
|---|---|---|
| 波动率判档 | ~10 | **3** |
| 网格/止盈/档位 | ~24（低中高各一套）| **~5**（\(k_{grid}\)、\(r_{tp}\)、exp系数、max仓位、mult上限）|
| 趋势 + 风险 | ~16 | ~8 |
| **合计** | **~50** | **~16** |

→ 降维后："分别优化高中低 + 切换 + 三方案逼近"的一周流程消失；组合爆炸缓解；各窗口最优会收敛。

## 4. walk-forward 自动化（点 2）与稳健参数选取（点 3）

### Python 自动化 walk-forward（降维后再做）
- 思路：Python 当指挥——对每个滚动窗口生成 MT5 测试器配置 `.ini`（含 `Expert/Symbol/Period/FromDate/ToDate/Optimization=1`）+ `.set`，命令行 `terminal64.exe /config:xxx.ini` 启动优化；MT5 输出优化报告（XML）；Python 解析→选训练段最优→测试段（`Optimization=0`）复跑取样本外→滚动下一窗口→汇总。
- 滚动方案示例：训练 12 个月 → 测试后 3 个月 → 前滚 3 个月，覆盖 2017-05→2026。
- **降维后才值得做**（否则仍在优化怪兽）。可由我写编排器。

### 各窗口最优"没共性"怎么办（点 3）
- **不要平均互相矛盾的最优解。** 正确做法：
  1. 降维后各窗口最优大概率**聚成一团**（参数少且物理，散不开）；
  2. 选"在**多个测试窗口都靠前**"的参数——按各窗口测试分数的**中位数 / 最差值**排序，而非单窗口最高分；
  3. 或找各窗口"好参数区间"的**交集高原**；
  4. 若降维后**仍**散成无关几组 → 结论即"无可靠全天候边缘"，转 A 路线。
