# eva028 阶段1测试指南（24.3参数）

## 1. 本轮改动边界

- 保留原24.3的全部154个输入参数名和当前值；新增9个阶段1参数。
- `InpUseDynamicLot=false`、`InpLotSize=0.01`，本轮所有核心对比固定0.01手。
- 不修改入场信号、网格距离、趋势识别和原有出场逻辑。
- 新增：参数校验、网格整篮金额止损、网格专属冷静期、策略日损停止、账户净值高水位回撤锁。
- 删除唯一经静态调用图确认无调用的函数 `CountPositions`；仍可到达的旧评分、审计、面板、MTF/ADX兼容分支全部保留。

## 2. 文件用途

- `eva028_24.3_baseline.set`：阶段1总开关关闭，用来确认新EA能复现原24.3。
- `eva028_24.3_basket_sweep.set`：只启用网格整篮止损；优化变量仅有 `$20/$30/$40` 三档。日损与永久锁关闭，避免遮蔽整篮止损效果。
- `eva028_24.3_stage1_full.set`：完整阶段1，默认整篮 `$30`、日损 `$20`、高水位回撤 `15%`。

## 3. MT5统一测试设置

每一轮都保持以下设置完全一致：

1. EA：`eva028_VolumetricPulseGrid_CoreRiskV1.ex5`。
2. 品种：你原回测使用的 Exness 黄金品种（包括后缀也必须一致，例如 `XAUUSDm`）。
3. 周期：M1。
4. 模型：`Every tick based on real ticks / 每个点基于真实点`。
5. 初始入金：USD 400。
6. 杠杆、账户类型、佣金和执行延迟：与原24.3回测一致。
7. 固定手数：`InpUseDynamicLot=false`，`InpLotSize=0.01`。
8. 不使用 Forward 自动切分；训练年与验证年分别单独跑，防止日期口径混乱。

## 4. 执行顺序

### A. 编译与24.3复现门槛

1. 把 `.mq5` 放到 `MQL5/Experts`，在 MetaEditor 中按 F7。
2. 必须得到 `0 errors`。若有 warning，也把完整编译输出发回。
3. 加载 `eva028_24.3_baseline.set`，分别单跑：
   - 2023-01-01 至 2023-12-31（压力/历史诊断）
   - 2024-01-01 至 2024-12-31（24.3训练期）
   - 2025-01-01 至 2025-12-31（24.3真正样本外验证期）
4. 基线复现不过关时先停止，不能直接评估阶段1。交易数应接近原结果：2023约253、2024约321、2025约476；差异超过1%，先检查品种后缀、真实tick历史、账户类型、时区和测试日期。

### B. 只训练整篮止损阈值

1. 仅使用2024训练期，加载 `eva028_24.3_basket_sweep.set`。
2. 开启 Optimization，优化准则选 `Custom max`。
3. 确认只有 `InpMaxGridBasketLossMoney` 打勾，范围为20、30、40；其余参数不得优化。
4. 导出完整优化结果为 XML；不要只发排名第一的截图。
5. 选阈值时按以下顺序：先看最大净值回撤和恢复因子，再看净利润/PF，最后看自定义分数。优先保留至少70%基线利润、PF不低于1.10，并显著降低尾部回撤的候选。

### C. 冻结后做真正样本外验证

1. 从B中选定一个阈值后冻结，不再修改。
2. 在2025-01-01至2025-12-31单跑一次。
3. 如果2025结果不好，不允许回头用2025调阈值；应记录为验证失败，再检查机制设计。

### D. 完整阶段1叠加

1. 把选中的整篮阈值写入 `eva028_24.3_stage1_full.set`，其他默认保持：日损20美元、永久锁15%。
2. 分别跑2024、2025；再用2023做压力测试。
3. 注意：日损20美元小于整篮30/40美元时，日损会先截断同日风险，这是完整保护层的预期；因此整篮阈值的独立优劣必须在B中关闭日损后判断。
4. 2026年数据只能作为额外走查，不参与重新选择阈值。

## 5. 每个结果需要返回什么

每个单次回测请返回：

1. Strategy Tester 保存的完整 HTML 报告。
2. 使用的 `.set` 文件；若手工改过参数，必须返回实际保存后的版本。
3. Journal/Experts 中包含 `eva028阶段1` 的日志行。
4. `Common/Files/eva_audit/<run_id>/` 下的三个CSV：
   - `eva_trade_events.csv`
   - `eva_decision_audit.csv`
   - `eva_run_config.csv`
5. 优化轮额外返回完整 XML（含全部3个pass），以及最终选中pass的单次回测HTML。

## 6. 实盘前最后检查

- 先在Exness模拟账户按固定0.01手运行至少2周，核对日志、成交原因和服务器自然日解锁。
- 永久锁触发后不会因重启MT5自动解除。人工复核后，把 `InpResetStage1LocksOnInit=true` 启动一次，再立即改回 `false`。
- 实盘发生入金或出金后也要执行同样的人工复位，让净值高水位以新资金基准重新开始；否则出金可能被识别为回撤。
- 本轮通过前，不开启动态手数，也不继续优化原入场参数。
