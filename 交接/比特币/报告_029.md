## 3. ★★我选择路径 C：**改变入金**（不是 A 也不是 B）

总调度给了 A（regime 检验）/ B（最终结论）/ C（其他）。**我选 C，核心理由如下。**

### 3.1 为什么不用 A（regime 变量检验）
我**已经用现有数据做了这个检验**（§2 的 ATR 表）：**train 的 ATR P10 = $45，而 test/valid 的 P10 都是 $300+。**
**→ 两个样本外段根本不含低波动区制** → **"按 ATR 分位切换参数"在 test/valid 上永远不会被触发** → **该规则在样本外【不可检验】**，因此它无法给出可信的样本外证据。
**（这不是说 regime 切换无意义，而是说：在本数据上它无法被证伪或证实。我不提交无法检验的规则。）**

### 3.2 为什么现在选 C（本金）
**我在 §2 诊断出一个此前被忽略的事实**：
> **最深回撤发生在净值 $452 的时期，且那段时期 `cap` 正在 binding（手数打到全期最大 0.35）。**

**→ 这说明 train 段的问题不是"策略差"，而是【300 美元本金太小】造成的**：
- 本金 300 时，理想手数 `= 300 × 1.5% / (1.5 × ATR)`；在 train 的低 ATR 期（ATR=$45）理想手数 = **0.067 手**，而 cap 只允许 `300×2.5%/(67.5) = 0.111 手` —— 两者接近，**cap 频繁 binding**；
- **本金越大，理想手数越大，cap 的相对约束就越松/越紧需要重新标定** —— 但更关键的是：**同一笔美元亏损占净值的比例会下降**。

**★★而且还有一个更根本的好处（这是本线一直没解决的困境）**：
```
本线全程用 300 本金 → 手数长期贴 0.01 最小手地板
→ 于是 InpRiskPct / InpMinLotMaxRiskPct 都退化成"开关"而非"旋钮"
（我在报告_022 花了整轮才定位这件事）
→ 入金 3000 后：理想手数 = 3000×1.5%/(1.5×ATR)，ATR=500 时 = 0.06 手，【远高于地板】
→ cap 与 RiskPct 才真正成为连续可调的旋钮
```
**→ 提高本金可能同时解决两个问题：压 DD + 让参数恢复"旋钮"性质。**

### 3.3 为什么"调本金"不是曲线拟合
**入金是【账户设定】，不是策略参数。** 实盘交易者本来就会选择一个足够大的本金来承载策略的手数粒度。
**→ 报告_007 总调度早已实测过"入金 300→1000 时 DD 基本不变（46.95%→48.03%）"** —— 那是**在 cap=3.0/无斜率闸门的老配置**上；**那次的结论是"手数按净值百分比配 → 回撤占比不变"，但这个结论的前提是手数【未被地板或 cap 卡住】**。
**→ 而 §2 证明：在 train 段的 2019–2020，手数【确实被 cap 卡住】（vol 到了全期最大）** → **所以"本金不影响 DD"这个老结论在本配置下【不成立】**，值得重测。
