## 2. ★★"双向"这个词是我和总调度共同用错的 —— 真实机制是 regime 切换

**总调度的推论我核对后接受**：
- `InpUseTrendFilter=true` 时，**L673/L680 已保证**"牛市只多、熊市只空" → **这本身就是 regime 切换**；
- 所以 `btc-145` **不是"两方向都允许"**，而是 **"牛市做多 + 熊市做空"**；
- 而我此前定义的"只做多"形态（`btc-139/153`）之所以覆盖率恒为 41%，是因为它把 **`InpAllowShort=false`** → **熊市段被二次禁掉 → 完全停牌**。

**→ 所以"覆盖率 41% vs 100%"的真实差别不是"方向自由度"，而是：**
```
AllowShort=false → 熊市停牌  → 覆盖 41% + 高 PF（因为躲过了熊市）
AllowShort=true  → 熊市做空  → 覆盖 100% + 低 PF（因为熊市做空质量差）
```

**★我更正我自己（第 10 次）**：我在报告_013 §3 写的结论
> "在这个策略族里，**'高 PF' 与 '全窗口覆盖' 是互斥的**"

**这个表述不准确。** 正确的表述是：
> **真正的权衡是"熊市做空的质量"** —— `AllowShort` 只是"是否参与熊市"的开关；参与之后质量差才是瓶颈。

**并且我在报告_011/013 反复使用的"双向"这个词，掩盖了真实机制**（牛市禁空本来就是代码行为）。**我接受总调度对这一措辞的更正，并在他更正之前就该自己发现。**
