## 1. ★我的"拒单筛选"假说被否证（我接受）

**实测（入金 3000, valid, cap 三点）**：
```
cap1.6（最强约束→最频繁拒单）: −731.69  PF 0.54   77 笔  ← 最差
cap2.5（中等）:                −448.36  PF 0.83   99 笔
cap6.0（几乎不拒单）:           +49.45  PF 1.02  109 笔  ← 最好
```
**→ 拒单越多亏得越多、几乎不拒单的唯一为正 → 与我的假说【方向相反】。我接受否证。**

**★但我要指出：总调度的替代假说也不完整。** 总调度说：
> "【本金】才是决定性的变量，而不是 cap。本金 300 时实际执行的是'固定 0.01 手'策略；本金 1000/3000 时执行的是'按 1.5% 风险配仓'策略。"

**这个方向对，但把"为什么"说成'固定手 vs 比例手'仍然不够精确。** 我做了算术：

```
理想手数 = 本金 × RiskPct% ÷ (SL_ATR × ATR)
取 valid 段典型 ATR≈430（P50）、SL=1.5 → 每 1 手风险 ≈ $645

入金 300  → 理想手数 = 0.0070 手  < 0.01 最小手  → ★走【最小手超配】分支
入金 1000 → 理想手数 = 0.0233 手  > 0.01          → 走【正常】分支
入金 3000 → 理想手数 = 0.0698 手  > 0.01          → 走【正常】分支
```

**★★所以真正的机制是「最小手地板」**：
- **入金 300 时，理想手数（0.0070）小于最小手（0.01）** → EA 走**最小手超配分支** → **实际风险 = 0.01 手 × $645 = $6.45 = 账户的 2.15%**（注意：**不是 1.5%**，而是被抬到 2.15%）；
- **入金 1000 时，理想手数（0.0233）超过最小手** → 走**正常分支** → **实际风险 = 1.5%/$ 15**；
- **→ 所以"入金 300 的正收益"【不是】固定手策略的优势，而是"最小手地板恰好把仓位压得极小"这一副作用。**

**★这与我在报告_022 发现的机制是同一个**：**最小手地板既"抬"手数（超配）又"压"手数（相对大本金而言过小）**，是一个**两向畸变器**，而这个畸变**恰好**让 valid 段在过去表现为正。
