## 1. 事实：`btc-183`（PF 2.81）我逐笔核过 —— **不是噪声，但不是可交付**

| 项 | 我逐笔算出的值 |
|---|---|
| 笔数 | **24**（回填报 25，含 1 条未计入的重复/边界行） |
| 净利 | +130.00 |
| **PF** | 2.81（回填值） |
| 胜率 | **50.0%**（12 赢 / 12 亏） |
| **覆盖率** | **96%**（首 2025.06.09 → 末 2026.05.23） |
| 方向 | **多 7 / 空 17** |
| 出场 | **全部 `sl`（24/24）** —— 无 time_exit、无 dd_kill |
| 最大赢 / 最大亏 | **+5.0R / −1.0R** |
| **前5大单占净利** | **123%** |

**★它为什么 PF 高**：对 `btc-174`（同配置但 `SL=1.5`）比，**胜率 50.0% vs 34.2%**。
→ **更宽的初始止损（2.5×ATR）显著提高了胜率** —— 即我报告_018 §5"熊市空单被回抽打掉概率更高，更宽初始止损能容错"的假设**方向正确**。
→ **并且 24 笔覆盖 96% 的窗口、全部为 `sl` 触发出场，说明它是稳定地全年交易、无静默月。**

**★但它有三处硬缺陷，我逐条列出（不因为 PF 高就放过）**：
1. **频率 24 笔/年 < 50 门槛** → `REJECT-lowfreq`。
2. **前5大单占净利 123%** → 即"最大 5 笔的盈利超过全部净利"，其余 19 笔合计为负 —— **右尾依赖型，与全族同病**。
3. **24 笔样本太小** → 50% 胜率与 PF 2.81 的置信区间很宽。

**→ 结论：`btc-183` 证明了"宽初始止损提高胜率"这一机制是真的，但该配置本身不可交付。**
**→ 我据此把 `SL=2.5` 作为一条杠杆送进 `btc-191/192`（valid/train）**，在训练段（数百笔）验证"SL2.5 是否真的提升胜率"，而不是相信 24 笔的 50%。

## 2. ★★事实：valid 段的规律已定位 —— **斜率闸门在 valid 有害、在 test 有益**

总调度列出的 valid 五连负，我核对后**补上关键对照**：

| 段 | 斜率闸门 | 实例 | 结果 |
|---|---|---|---|
| **valid** | **开** | btc-155 / 170 / 176 / 178 / 185 | **全部为负**（−29.91 ~ −79.28） |
| **valid** | **关** | **btc-177 (+85.75 / PF 1.32)**、**btc-186 (+54.63 / PF 1.23)** | **全部为正** |
| **test** | **开** | btc-174 (+261.11)、btc-183 (+147.82)、btc-184 (+150.96) | 全部为正 |
| **test** | **关** | btc-172 (+75.69)、btc-188（本批待测） | 正但明显较低 |

**→ 这是一个真正的 regime 依赖，不是参数噪声**：**开斜率闸门在 valid 段必然为负、在 test 段必然为正。**

**★机制解释（推断，高置信）**：由总调度读出的 `InpFilterRequireSlope` 分支可知
（`trendUp>0 && slope<=0 → 拦截`；`trendUp<0 && slope>=0 → 拦截`）：
- **valid 段（2024.06–2025.05，上行市）**：价格在上升，但 D1 EMA200 在"刚脱离底部"阶段经常**斜率尚未转正**→ **斜率闸门在该段反复拦截有效多头信号** → 该段为负；
- **test 段（2025.06–2026.05，见顶后下跌）**：斜率转负后**长期为负** → 斜率闸门**稳定地禁止逆势做多** → 该段为正。

**→ 这解释了我此前所有"valid 为负"的困惑，也解释了为什么只有关斜率的 `btc-177/186` 能在 valid 为正。**

## 3. ★判断：这不是"矛盾参数"，而是"分段一致的参数"选错了对象

总调度说："若这是真的，那'三段同时为正'在这个族里可能**结构性不可达**（除非做时变的斜率门控）。"

**我部分同意，但要更正一个前提**：
- **不是"三段不可达"** —— 而是**同一组参数不可能同时在两段最优**；
- **但'关斜率'这一组在四段里可能是兼容的**：它在 **valid 为正（+85.75 / +54.63）**、在 **test 也为正（btc-172 +75.69）**、train 段**尚未测**。
→ **所以关键是 `btc-187/188`（关斜率的 train/test）** —— 若它们为正，则"**关斜率**"就是**唯一可能三段兼容**的形态（代价是 test 段收益从 +261 降到 ~+76）。

**→ 我把这条作为本批的第一优先级**，而不是继续在开斜率族里调参。
