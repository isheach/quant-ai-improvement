**三条读法**：

2. **验证/测试窗口在几乎每一档都 PF > 1** → 这两段是金价 2300→4560 的强趋势期。

**★我要特别标出一个反向指标**：`SL_ATR=1.00` 在验证段 PF 1.521（好）但测试段 **0.638**（差）——
**同一档位跨相邻两段方向翻转**，这正是"参数-时段耦合"的典型症状。

## 3. ★三个必须先解决的量级问题（我在数据里发现的，不解决则上述结果不可交付）

### 3.1 net = 97,182.97 对 300 本金 —— 连续复利把仓位推到荒谬量级（**high**）

测试段最大一条：`SL=0.25/DC=24/RK=3.0` → **net = +97,182.97**、133 笔、 PF 2.200、`expected_payoff = 730.70`。
- 300 → 97,483 是 **325 倍**。要 133 笔做到，需要每笔约 **+4.5%/笔** 的复利。
- **每条 `expected_payoff ≈ 730 美元`** —— 而账户起始只有 300。
- **DD_pct 56.2%**，对应美元回撤约 **5.5 万**。
→ **这是"按净值百分比配仓 + 无手数上限 + 133 笔连续复利"的产物，不是策略表现。**
→ 1 手黄金 = 100 盎司 = 名义 40 万美元；**`InpMaxLot=100` 允许的手数远超任何 300 美元账户的合理量级**。

**我自己的责任**：`InpMaxLot=100.0` 是我在 `fixed` 里显式写的（沿用源码默认）。
→ **已在第五批加入封顶对照组**（`gold-078/079/082` 等）。

### 3.2 测试段冠军 net=97,182 是个**做多 2025-26 黄金牛市**的杠杆表达（**medium-high**）

测试窗口 2025.06–2026.05 金价 3300→4560（**+38% 单边上涨**）。
`n=133`、`SL=0.25×ATR`（极紧）、方向过滤是 D1 EMA（在单边牛市里几乎恒为多头）。
→ **"紧止损 + 全程多头 + 单边上涨" = 任何策略都会赚钱**，与是否有 edge 无关。
→ 与 §2 的训练段（同逻辑 PF 0.718）对照，**这是时段性质差异，不是策略能力差异**。

### 3.3 `InpVolNormalize` 的多档位给出**完全相同**的结果 → 该机制目前基本没起作用（**high**）

goldgrid-004 里：
```
SL=0.5 RK=2 VM=0.8 VX=2.0 → net 53.34 pf 1.150207 n=111 dd 43.5594
SL=0.5 RK=2 VM=0.8 VX=2.5 → net 53.34 pf 1.150207 n=111 dd 43.5594   ← 完全相同
SL=0.5 RK=2 VM=0.8 VX=3.0 → net 53.34 pf 1.150207 n=111 dd 43.5594   ← 完全相同
```
**三档上限 2.0/2.5/3.0 结果逐位相同** → **归一化系数从未触及上限**。
→ **你说"波动率归一化可能正好解决闸门问题"——就当前参数而言它没有生效**（系数被夹在很窄的范围内）。
→ 第五批 gold-085 专门在长窗口验证它到底有没有作用。
