## 1. ★我撤回"事件驱动"结论（我的错误，两个原因）

### 1.1 你的证据

| 段 | net | PF | 笔数 | 时长 | 笔/年 |
|---|---:|---:|---:|---:|---:|
| **危机前 `gold-097`**（2017.05–2020.01） | **+220.90** | **1.24** | 308 | 3.7 年 | 83 |
| **危机窗 `gold-099`**（2020.02–2022.05） | **+191.35** | **1.25** | 253 | 2.3 年 | 110 |

→ **两段 net 与 PF 几乎相同，而危机前的时间更长。** 我的"事件驱动"结论**不成立**。

### 1.2 ★错误的根源：我用了一个有偏统计量

我当时的推理是"按**美元 pnl** 排序取前 10 大单 → 全部落在 2020-2022 → 所以是事件驱动"。
**但这个统计量的分母是仓位，而仓位 = 净值 × 风险%，随权益曲线单调增长**：

```
gold-093 手数: 中位 0.03、最大 0.10   → 末段仓位约为初段的 2.8 倍
→ 同样 R 的一笔赢单，2021 年的【美元金额】天然是 2017 年的 ~2.5 倍
→ 「按美元排序取前10」必然偏向测试后段（高权益期）
```
**→ 我读到的"事件集中"是权益增长的产物，不是策略性质。**
**正确做法应该是按 R（= pnl / risk_money）排序，而非按美元排序。** 我当时手上还没有 R 列（受 §3 的 `entry=0` 缺陷限制），于是误用了美元。

### 1.3 固定手之后的证据（决定性）

| 数据集 | 手数 | 前5大单占净利 | 前10大单占净利 | **去掉前10大单** |
|---|---|---:|---:|---:|
| `gold-100`（**固定 0.01 手**，holdout 8.4 年） | **全部 0.01** | **63.1%** | **99.9%** | **+0.56** |
| `gold-097`（可变手，危机前） | 0.01–0.08 | 94.1% | 143.8% | −223.68 |
| `gold-099`（可变手，危机窗） | 0.01–0.04 | 114.9% | 188.4% | −307.35 |

**→ 固定手把集中度从 143.8% 降到 99.9%，且危机前/危机窗的 PF 几乎相等。事件解释被排除。**

## 2. ★但"尾部依赖"是真的，而且是本线的核心风险（high）

`gold-100`（**纯固定 0.01 手**，578 笔，逐笔合计 +482.55）：

```
前 5 大单 = +304.55  →  占 63.1%
前 10 大单 = +481.99 →  占 99.9%
去掉前 10 大单后 = +0.56 ≈ 0
出场: sl=556  time_exit=22        （556/578 = 96.2% 止损出场）
```

**读法（这是趋势跟随的教科书形态，也是它的固有脆弱性）**：
- **绝大多数交易是小额止损**，全部净利来自极少数抓到趋势的单子
- **去掉 578 笔里不到 1.8% 的 10 笔，edge 就归零**
- → **不可交付的理由不是"没有 edge"，而是"edge 依赖每次都能抓到那几个离群赢家"**
- → **这类策略**（低胜率 ~16%、高盈亏比 ~7.9）**理论上可接受，但要求执行零缺陷、
  且不能依赖"每次都能抓到"** —— 抽样误差会直接决定盈亏

**我不主张因此淘汰它，但主张把它作为硬门槛**：任何候选**必须报告"去掉前 N 大单后的净利"**（N=5/10/20），
而不只是"前5大单占比"。

## 3. `gold-100` 是第一个 DD<20% 的口径 —— 但有个换算问题

```
gold-100  固定0.01手  holdout  net=+248.17  PF=1.26  567笔  DD=19.15%  ann=9.88%
gold-093  可变手      holdout  net=+696.00  PF=1.26  563笔  DD=34.45%  ann=27.7%
```
**你观察得对**：**PF 几乎不变（1.26 vs 1.26），但 DD 从 34.45% 压到 19.15%** →
**这证明 DD 主要由仓位放大驱动**（与我在报告_009 §2.2 的更正一致），且**复利约贡献 2.8 倍净利**。

**★换算问题**：固定 0.01 手在 300 本金上单笔风险 ≈ **$6 = 2%**，**违反用户"≤1%"约束**。
**但 0.01 手黄金的美元风险与账户大小无关**（这是我在报告_003 §2.5 立过的硬约束）：
```
入金 300  → 单笔风险 2.0%   ❌
入金 600  → 单笔风险 1.0%   ✅ 正好达标
入金 1200 → 单笔风险 0.5%   （可再降）
```
**→ 而 edge 在 R 口径下与账户大小无关**（固定手时每笔 R 完全相同）
**→ 所以入金 600 应复现 gold-100 的 PF 1.26 与 DD ~19%，同时把单笔风险压到正好 1%。**

**这就是第九批 `gold-102/103/104` 的设计** —— 本线**第一次尝试同时满足**"单笔风险 ≤1%"与"DD <20%"两条硬约束。
