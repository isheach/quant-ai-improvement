```
USD 计价品种: calc = (exit - entry) * contract * vol * dir
JPY 计价品种: calc = (exit - entry) / exit * contract * vol * dir   ← 除出场价换回 USD
```

## 说明：14143 倍异常的核查结论

历史记录里 JPY 曾出现 143 倍量级异常。本脚本用【当前审计格式】的 JPY run 重算，
若比值≈1，则说明：
1. 当日异常来自 **`SYMBOL_TRADE_TICK_VALUE` 在 tester 里的漂移**（该字段不可信）；
2. 或来自 **某一版 EA 的换算实现**（现已改为合约规格比手算）。
3. 无论哪种，**当前审计链路是自洽的** —— 可用它做 JPY 对账基准。
