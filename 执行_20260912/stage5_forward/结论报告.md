## 4. ★★ 与子代理历史结果的差异已定位（**不是矛盾，是配置不同**）

```
子代理 btc-282 (valid, 入金1000): −25.99
我 P4D1000      (valid, 入金1000): +95.18
```
**逐项对照 `inbox_比特币.jsonl` 与我的参数，三处差异**：

| 参数 | 子代理 btc-282 | 我的 P4D1000 |
|---|---|---|
| `InpUseDDKill` | **true** | **false** |
| `InpMaxDDPct` | **25.0** | （未启用） |
| `InpDDCooldownMin` | **1440** | （未启用） |
| `InpTrail_ATR` | **3.5** | 默认 |
| `InpFilterSlopeBars` | **10** | 默认 |

**→ 所以 −25.99 vs +95.18 **不是数据矛盾**，而是**DD 锁 + Trail 3.5 的组合在 1000 USD 下把 valid 打成负值**。**
**→ 这实际上是一个**新发现**：`InpUseDDKill=true` 在 valid 段是**负贡献**（本次同段对照：false → +95.18）。**

**★这条与我在 Stage4 的推断（"500 落在过渡带"）无关** —— 那个推断的否证见 §3。
